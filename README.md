# Bank2Html
Vanilla 1.12.1 addon for World of Warcraft that exports a list of all items in all your characters bags and banks to an HTML page.

## Installation
1. Download **[Latest Version](https://github.com/maloch11/Bank2Html/archive/refs/heads/main.zip)**
2. Unpack the Zip file
3. Rename the folder "Bank2Html-main" to "Bank2Html"
4. Copy "Bank2Html" into Wow-Directory\Interface\AddOns
5. Restart Wow
